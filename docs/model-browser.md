# GGUFモデルブラウザ

初回設定から「おすすめモデルを使う」「モデルを検索する」「手元のGGUFを使う」「外部ローカルLLMへ接続」を選択できます。おすすめも同じ検索ブラウザを利用し、Qwenのコード系モデルと空きRAMに合う条件を初期設定します。固定2択の選択画面はありません。

検索はHugging Faceの公開メタデータをHTTPSで取得します。最大40候補を取得し、ファイルメタデータを最大4並列で補完して絞り込みます。日本語・用途は配布者のタグや名称、規模はGGUFメタデータまたは名称、量子化はファイル名、容量は配布ファイル情報を使用します。ダウンロードや起動実績は検索条件に使いません。モデルカードは非実行の平文として表示します。

PC適合は空きRAM・ディスク・専用VRAMの目安です。CPU Runtime / context 8192を基準に、モデル容量に3GiBの余裕を加えます。この固定余裕はKVキャッシュを正確に予測するものではありません。VRAMフィルターは容量の比較のみで、GPU実行を有効にする設定ではありません。統合GPUの共有メモリを専用VRAMとして数えません。

ライセンスが既知の寛容ライセンス（Apache-2.0、MIT、BSD、ISC、CC0）の場合に配布条件フィルターへ含めます。モデルカード独自条件やベースモデルの条件を法的に判定するものではなく、導入前の確認が必要です。独自ライセンスのモデルも確認欄を選んで導入可能です。すべての導入でHTTPS・固定Revision・サイズ・SHA-256・GGUFマジックを検証します。分割GGUF、SHA-256不明の配布ファイルは導入しません。モデル付属のPythonやremote codeは実行しません。

検証済みモデルはassets/model/<SHA-256>/artifactへ保存し、host/llm.jsonへRuntime・ハッシュ・以前の状態と導入後試験を登録します。起動・最小推論が成功してから有効にします。試験失敗時は以前の登録を保持し、以前のRuntimeへ復帰します。手元のGGUFも管理領域へコピー・ハッシュ照合し、同じ試験を行います。最小挨拶の応答は日本語品質・構造化JSON・コード生成品質の合格を意味しません。それぞれ未評価と表示します。

検索は専用ワーカースレッド、PC負荷は2秒間隔の専用スレッド、通常のGUI更新は500ms間隔です。PC指標はシステム全体の値でSelfStruct単独の使用量ではありません。NVIDIAが取得できれば利用率・使用VRAMを表示し、その他のWindows GPUはDXGIで機種・専用メモリ容量を表示します。未取得値は0%としません。

研究室の新しい分割IDはlab-horizontalです。旧版の上下分割のピクセル位置は横分割に流用しません。左右分割・ログ分割・ブラウザの分割位置とウィンドウ位置は既存のLayout管理へ登録します。
