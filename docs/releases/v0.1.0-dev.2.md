画面と限定された入力から経験を集める、自律研究アプリケーションの初回開発版です。完成版ではありません。

## ダウンロードと開始

Windows 10/11・64bit向けの `SelfStruct.exe` をダウンロードして起動してください。PythonやGitの別途インストールは不要です。

初回設定でゲームの実行ファイル、許可キー、専用の保存先、容量上限を指定し、ローカルLLMを選んで自動導入します。導入にはネット接続と数GBの空き容量が必要です。設定後はSTARTで開始します。GUIのPAUSEで入力を解放し、STOPで終了します。

## 背面放置での利用

対象ゲームが背面や他のウィンドウに覆われた状態でも動作を継続します。ユーザーが別のアプリやゲームを操作しても、フォーカスの変化では停止しません。入力先は対象ウィンドウのみで、前面の強制切り替えやPC全体へのキー入力は行いません。止める場合はGUIのPAUSE / STOPを使ってください。

最小化は対象外です。Raw Input専用など、ウィンドウ宛てのキーメッセージを受け付けないゲームでは動作しない場合があります。全体入力への自動切り替えは行いません。

## 含まれる機能

- 日本語GUI、画面取得と許可入力、原画像を保持する経験保存。
- 非同期研究、仮説と根拠の記録、隔離された改善候補の比較評価。
- 採否判定、世代管理、異常時の巻き戻し、保存状態からの再開。
- 公式配布元とSHA-256を確認するローカル推論エンジン・モデル取得。

Windows上で公式エンジン・軽量モデルの自動取得、SHA-256照合、起動、実際の構造化推論も確認しました。検証結果は添付の `window-validation.json` と `inference-validation.json` に含めています。

## 制限

- 実際の未知ゲームでの長時間運転、有用な自己改造の成功は未検証です。
- 起動先が別プロセスへ渡るランチャー、すべての描画方式には対応していません。
- EXEにはAuthenticode署名がありません。本体の署名付き自動更新も未設定です。
- `SHA256SUMS.txt` と `build-info.json` を添付しています。詳細な利用方法・検証状態はリポジトリのREADMEとdocs/validation.mdを確認してください。

AIの強さやゲーム攻略の成功を保証するリリースではありません。
