# SelfStruct 0.7.9

LLMが選べる観測解像度の指定に `size="fit"` を追加します。選んだ領域を縦横比を保って既存の262,144画素以内へ縮小し、小さい領域は拡大しません。全画面の概観にも、LLMが指定したboxにも使えます。原寸や数値指定の要求を黙って変更する処理ではありません。

## 変更と検証範囲

`fit` はLLMが明示的に選ぶ観測方針です。例えば1600×900の全画面なら682×384として取得できます。原寸の文字を読むためにboxとnativeを使う方法、従来の任意の数値解像度指定も残します。数値指定やnativeが上限超過なら引き続き拒否し、有効な解像度の例とfitという代替をエラーに返します。画素・画像送信・推論回数・時間の上限は増やしません。

結果と診断に、要求したfit方針、実際の出力解像度、元の領域と座標変換を残します。Text-onlyでは既存の値数上限と部分取得の明示を維持します。固定出力形状が必要な再利用解析器では、nativeと同様にfitを拒否し、数値指定を要求します。

Vision・Text-only双方の自動Harnessで、実画像の領域エラー→原寸の面積エラー→LLM役がfitを選択→同じJobへ観測返却、を確認しました。指定した領域・色・原座標の保持、小領域を拡大しないこと、数値指定とnativeを自動縮小しないことも検証しています。これはスクリプト化した選択によるAPI接続の検証で、利用モデルが自力でfitを選ぶことや目的達成の証明ではありません。

次の実機診断では、`size="fit"` の選択、実際の配信解像度、上限エラーの減少、取得した結果からの理解更新・次入力を確認します。0.7.8の仮説タブと分割位置保存は維持し、研究室のバージョン表示は0.7.9へ追従します。
