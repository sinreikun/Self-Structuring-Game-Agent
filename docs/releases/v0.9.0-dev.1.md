# SelfStruct 0.9.0 — single-link-research-jobs

## 変更

0.8.0（connected-research-loop）以降の研究機構をまとめて収録します。製品の研究対象・予算・統計ゲートの算術は変えていません。

- 状態遷移の研究：状態定義（findings 経由）、遷移クレーム {from_state, action, to_state, probability} の事前登録、Gate A の対象化、Host 側の状態同定（代表フレーム集合に対する類似度）、Gate B と Job 終了時自動評価の遷移対応。
- 粗い状況ループ：代表プールの蓄積（上限20、登録時に凍結）、無入力ベースライン観測と差分配信、粒度ガード（警告）、状況候補の生成（直近64経験のクラスタ）と提示、候補採用の遷移クレームへの同梱（原子的登録）。
- 運用の健全化：ポーズ原因の記録、ウォッチドッグの段階進行セマンティクス、Store ロックの保持者計測、使用量走査と GC 列挙のロック外化、使用量索引（host/usage-index.sqlite3）の導入、研究時の画像比較のロック外化。
- 研究 Job の形：observe の無駄の削減（上限超過の縮小実行、重複観測の参照化と非課金）、Job 開始時のアジェンダ提示（未完の鎖の台帳）、**単一リンク Job**（最上位の未完リンク1件を担当として固定し、文脈を担当中心に組み立て、担当外のクレーム登録と実験を非課金で差し戻し、リンク閉鎖・放棄・予算で終了）、登録済みクレームと異なる同梱クレームへの差し戻しへの登録内容と再送手順の同梱、単一リンク文脈の削減（冒頭 input 6,588 → 3,697 トークン）。
- 評価の標本集計の統一：台帳・Scientist の evaluate・Host の終了時自動評価が、登録以降の全標本という同一の集合を使うようにしました。16件未満の評価は途中経過として記録され、成熟後の最終評価を妨げません。
- 方針文書（ssga-direction-policy.md）と単一リンク設計書（single-link-job-design.md）を同梱。

対象コミット：8495a2c（遷移研究）、4beecf2（参照固定と画像抑制）、d42ae4e（方針文書）、52326e4〜d549633（粗い状況・ポーズ記録・ウォッチドッグ・ロック計測・使用量のロック外化・使用量索引）、d0e257f（画像比較のロック外化）、f05ddd3／d0fcf31（状況候補と同梱採用）、28a34a8（observe の無駄対策）、fc81f9c（アジェンダ開始と文書）、c61e3cd（単一リンク Job）、55cbe95（差し戻し文面と文脈削減）、cab5950（評価集計の統一）。

## 実機証拠と限界

単一リンク Job の主証拠は GEN-0006（長命の本番個体、知識2,600件超）での監査セッションです。Job c9d50d1f が claim 2116（8/16）を担当し、その鎖だけを進めて標本 1+8 を集め、link_closed で終了しました（5 calls、画像配送2件）。モデル自身が evaluate を実行し（評価25、pre_registered=true、標本不足のため inconclusive）、評価を含む研究報告24が保存されました。一方、標本0のリンク（claim 2121）では続く2セッションとも担当への実験要求は合計0件で、前進しませんでした。単一リンク機構は足場のあるリンクでは鎖を完走させますが、冷たいリンクではモデルの実行駆動が残る壁です。

出荷前スモークは GEN-0007（新規個体、知識ゼロから本番稼働中）で本版候補ツリーを用いて実施しました（2026-11-05、監査ハーネス経由）。Job 905e489d で担当 claim 61（行動 W、確率0.5）が固定され、画像配送2件、担当への実験3件が完了して標本13件を蓄積、モデル自身の evaluate 3件はいずれも16件未満の途中経過として inconclusive に記録され、研究報告2件が保存されました。Job は actions 予算で終了し、リンクは未閉鎖です。次の Job は claim 70 を担当として引き継ぎ待ちになっています。

なお GEN-0007 は製品版 0.8.0 の本番稼働で評価4件（n=16・事前登録、うち2件はモデル自身の evaluate）を完走していますが、それは本版の証拠ではありません。本版の本番アプリでの稼働は未確認です。また、状況遷移の5条件（プール3件以上・ベースライン補正済み標本・遷移クレームの判定・状況マップを含む報告）は本版でも未達成で、粗い状況ループの到達点はベースライン記録までです。GEN-0006 は検証後に削除され、現在の本番個体は GEN-0007 です。
