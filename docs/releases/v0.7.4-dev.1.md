# SelfStruct 0.7.4

現行モデルに対応する視覚入力用ファイルがあるのに読み込まず、Text-onlyとして動作していた欠落を修正します。研究の目的・プロンプト・入力予算・操作上限は変更しません。

## 目的との関係と根拠

大目的は対象の仕組み・目的を理解し、それに沿って操作することです。同一のGemma 4 12B Q4_K_Mで解法を教えない通常研究を実行したところ、要求した全画面のうち左上64値しか次の推論へ届かず、この画面の指示・図形を含んでいませんでした。CPU環境では2回目の推論中に660秒制限へ達したため、自律判断の最終結果は未確認です。

同じ固定版のprojectorを読み込んだ視覚単独検証では、同じモデルが実際の画面の指示文と左右の図形配置を正しく説明できました。これで前進したのは、対象の目的を示す画面情報へアクセスする前提条件です。指示付きの単独検証であり、自律的な観測選択・操作・目的達成の実証とは区別します。

## 修正

- HFの同じ固定Revisionを参照し、重みのSHA一致、標準名のprojector、サイズ・SHAを確認して取得します。曖昧な対応は推測しません。視覚ファイルは言語モデル一覧へ登録しません。
- 起動時に対応モデル・保存先・SHAを再確認し、エンジンへ `--mmproj` を渡します。画像対応はRuntimeの能力申告で判定します。
- 新規導入と既存モデルのSTARTに対応します。取得・起動に失敗したら理由を残し、Text-onlyへ戻します。キャンセルを無視して取得・再試行しません。
- 画像を見るか、どの範囲・解像度・操作を選ぶかはLLMに残します。画面や過去の全文の自動投入は追加しません。

[目的に沿う研究の検証](../goal-directed-validation.md)に検証方法、失敗と未確認の区別、実機での確認条件を記載しています。既存の個体・モデル・Launcher 1.1.0を使用できます。
