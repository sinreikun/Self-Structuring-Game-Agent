起動中のプロセスへの接続と、ランチャー経由のゲーム起動に対応した開発版です。

## 接続方法

- 起動済みのゲーム：「初回設定」→「起動中から選択」でゲーム本体のアプリ名・プロセスID・ウィンドウを選択します。名前や番号で検索できます。
- 起動用EXE・ランチャーを使うゲーム：「接続方法」を「ランチャーから起動」にし、起動用EXEを指定します。ランチャー自身ではなく、その起動から生まれるゲーム本体の画面を待ちます。ランチャーが先に終了しても検出を続けます。
- サービス経由など、子プロセスとして検出できない起動経路：通常の方法でゲームを起動してから「起動中から選択」でゲーム本体へ接続できます。

接続した既存ゲームはSTOPや復旧処理で強制終了しません。選択したプロセスが終了した場合は、一覧から選択し直してください。PIDと起動時刻を照合し、同じ番号を再利用した別プロセスへの誤接続を防ぎます。

このアプリが実行ファイル・ランチャーから起動したゲームは、従来どおり自動復旧時に再起動できます。

## 今回の検証範囲

ユーザー指定に従い、プロセス選択・GUI設定保存・既存プロセスへの入力と切断・ランチャー終了後の子プロセス接続・ウィンドウ再検出・EXE内の同じ接続処理に絞って検証します。

推論・学習など無関係なテストは再実行しません。変更していない推論実装・依存定義・設定保存関数は検証済みv0.1.0-dev.3とハッシュで比較し、推論検証の再利用をレポートに明示します。今回新しく推論試験を行ったという意味ではありません。

Num0〜Num9の設定と背面動作は引き継いでいます。最小化、背面のキーメッセージ入力に対応しないゲーム、未知ゲームでの長時間学習の成功は引き続き保証していません。Authenticode署名と署名付き本体自動更新は未設定です。
