# SelfStruct 0.7.8

研究室の「自作器官接続図」の枠をタブ化し、先頭に「現在の仮説」を追加しました。ロード中の個体の直近20件の仮説を文章の折り返しとスクロール付きで表示します。稼働中は更新し、停止中も保存された仮説を確認できます。「自作器官接続図」は2番目のタブへ移動しました。

入力ログとLIVE TRACEの境界、個体管理・LLM管理の左右境界、LLM管理内のモデル一覧と詳細の上下境界を終了時に保存し、次回の表示時に復元します。未表示のタブの初期位置で保存値を上書きしません。入れ子になった親枠のサイズ確定後も復元するため、起動のたびに境界が少しずつ移動する問題を防ぎます。

研究・入力・LLMの動作は変更していません。研究室のバージョン表示は0.7.8へ追従します。

## 検証

実際のTkウィンドウで仮説の表示、先頭タブ、折り返し設定、4つの分割位置の変更→終了保存→再起動→復元を確認しました。再起動後に一部タブを一度も表示せず再保存する経路も確認しています。
