ゲーム画面を主役にした研究コンソールと、GGUFモデルブラウザを追加しました。

- 左に大きなゲーム画面、右に活動・日本語イベント・入力履歴・LIVE TRACE・Agent自己記述の能力図、下に操作・集計・保存容量を配置。
- LIVE TRACEは実際の観測・送信済み入力・変化計算・DB保存・学習・LLM・評価・採否・復旧イベントのみを表示。最近35行と入力10件を保持します。
- PC全体のCPU使用率、RAM使用量、ディスク空き容量を低頻度で非同期表示。NVIDIAはGPU使用率・使用VRAM、WindowsのDXGI対応GPUは機種・専用VRAMを取得し、取れない指標は未取得と表示します。
- 固定候補の選択欄をモデル検索ブラウザへ変更。Hugging Faceの公開GGUFをキーワード・用途・規模・量子化・容量・PC適合・ライセンス・並び順で探せます。
- モデルカード冒頭、量子化別ファイル、SHA-256・容量、モデル規模、作者、更新日、DL数、ライセンスと適合目安を表示。
- 固定Revision・SHA-256を検証した再開可能ダウンロードから、管理Runtime登録・読み込み・最小推論試験までアプリ内で実行。手元の単一GGUFと外部ローカル接続先も利用可能です。
- 既存Launcher 1.0.0の同一ファイルを継続利用。本体更新ではLauncherを置き換えません。

制限：検索は1回最大40候補内で絞り込みます。分割GGUFは未対応です。配布条件フィルターは既知の寛容ライセンスの識別子に基づく目安で、モデルカードの確認が必要です。「高性能」は14B以上の規模目安で、実測品質ではありません。PC適合は現在のCPU Runtimeとcontext 8192、モデル容量と推定余裕から計算し、動作速度や研究成功率は保証しません。日本語品質・JSON・コード生成の詳細試験は未評価と区別します。

既存の経験・保存領域GC・診断ZIP・レイアウト保存・背景入力の境界を維持します。過去個体の画像を新たに削除する変更は含みません。
