## 変更

- 同じJobの実験結果IDを小さい索引 `input_feedback` に保持します。最近2件の操作履歴から消えても取得先を失いません。実際に渡したbefore・after・比較、今回の入力で見えているもの、根拠ID付きの検討記録を区別します。画像・数値の実体がないメタデータだけを「見た」と数えません。
- 前の推論で完了した各実験計画について、少なくとも1つの実結果IDをfindings・研究メモ・研究結果で検討するまで、次の研究実験を登録しません。以前の画像のIDだけでは通りません。「不明」も記録できます。同じ応答で事前計画した複数実験は実行できます。観測方法や入力の選択はLLMに残します。
- 要求済みの同じ実験の前後画像が、短い返答とともに現在の入力枠へ収まる場合は、返答用の予約を512トークンとして両方を残します。8192の入力枠や研究回数・時間・画像予算、統計評価基準は増やしません。
- 検討記録と実際の配信状況を診断に保存します。研究室のバージョン表示は0.7.7へ追従します。

検討記録は根拠の参照があることの確認であり、内容の正しさや仮説の支持を保証しません。画像取得そのものも強制しません。観測値だけで判断できる場合と、意味が未確認な場合を区別して記録できます。
