AgentとScientistが同じ画面Evidenceへアクセスし、どこを・どの解像度で・どう調べるかを研究できるようにしました。

- RGB/輝度・可変解像度Crop・画素ページング・差分・統計・連結領域・比較を共通APIで利用できます。
- Scientistが追加観測を繰り返せます。画像入力対応をRuntimeが明示する場合だけ選んだ画像を直接渡し、非Visionモデルにも同じEvidenceの画素や解析結果を返します。
- 汎用演算を合成した解析器を個体に保存し、新しい独立経験で再現性・予測寄与・未知率・誤反応・コストを評価します。モデル変更後も資産を保持し、未評価・定数解析器を自動採用しません。
- AI注目領域・LIVE TRACE・能力接続図・研究ノートに実際の要求と出所を反映します。Replayから未来のAfter/Diffへアクセスすることは禁止します。
- 外部ライブラリ要求は記録し、公式署名付きカタログの汎用宣言的パイプラインだけをGatewayで取得可能にします。任意NativeコードやDLLは読み込みません。

既存の個体・経験・モデル・Launcher 1.0.0・更新プロトコルは保持します。画像や派生物の保存は既存GC・容量制限に従います。管理済みGGUFの任意projector自動導入や、未知ゲームの意味理解・攻略能力を保証する変更ではありません。詳しくはdocs/visual-access.mdを参照してください。

検証済み配布物・CI結果は公開準備時に追記します。
