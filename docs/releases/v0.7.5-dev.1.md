# SelfStruct 0.7.5

Vision対応の研究LLMへ、画面を直接見るための要求方法を明示します。研究室タブには実行中のアプリのバージョンを表示します。

## 提出診断で確認したこと

0.7.4のWindows実機では、対応projectorの取得・読込、RuntimeのVision申告、GPUへの49/49層の転送が成功していました。しかし研究4 Job・40推論で画像要求・画像添付・Experiment・研究結果の提出はいずれも0件。全4 Jobが推論回数上限で終了しました。

観測は29件成功・24件エラー・32件重複、比較は6件成功・1件重複。仮説46件はすべて未検証で、メモ4件はありましたが本文取得はありません。ゲーム側の通常Player操作と、研究LLMが目的・仮説に結び付けたExperimentは区別します。入力枠超過や新しいVision読込失敗が原因と確認した結果ではありません。

## 目的に近づけるための変更

0.7.4ではVisionが利用可能でも、共通の取得例は `output=pixels,limit=64` で、画像入力の可否は末尾のTrue/False表示でした。利用可能な画像経路をLLMが自発的に選ばない点へ対応します。

VisionをRuntimeで確認できたときだけ、画面の文字・UI・配置や目的を読み取るために `observe output=image` が利用できると明示し、共通の画素配列の例を画像要求の例へ置き換えます。pixelsは数値列、statisticsは要約であり、画像そのものを見ることと区別します。

画像・画素・統計はすべて選択可能です。実際の観測方法・領域・解像度・入力はLLMが選びます。Hostが画素要求を画像要求へ変換したり、最初から画面や履歴全文を投入したりする処理は追加しません。Text-onlyへ画像能力があるとは案内しません。主目的・研究予算・実験評価基準は変更しません。

## 研究室のバージョン表示

研究室タブ下部、操作ボタンと同じ領域の右側に `SelfStruct 0.7.5` を表示します。表示元はアプリ自身の `__version__` で、今後の更新でも実行中の版に追従します。
