テンキーの `Num0`〜`Num9` を許可キーに設定できなかった問題を修正しました。

Windows 64bit向けの `SelfStruct.exe` を取得し、実行中の旧版をSTOPで終了してから修正版を起動してください。PythonやGitのインストールは不要です。

次の一覧を「許可キー」へそのまま入力できます。

```text
UP,DOWN,LEFT,RIGHT,Num0,Num1,Num2,Num3,Num4,Num5,Num6,Num7,Num8,Tab
```

大文字・小文字は区別しません。Num0〜Num9はテンキーで、通常の0〜9とは別の入力として送信します。Num9も使用可能です。

背面動作と対象ウィンドウ限定の入力は引き継いでいます。停止はGUIのPAUSE / STOPを使用してください。

## 検証

- 設定画面で上記の一覧が受理されること。
- Windowsのテスト用ウィンドウへ、上段の数字キーではなくテンキーの仮想キーが実際に届くこと。
- Windowsの単体EXE起動・背面入出力・ローカルLLMの自動導入と実推論。

リリース工程は、同じコミットのCI成功・EXEのSHA-256・起動と推論の検証結果を確認してから配布します。

## 制限

開発版です。最小化や、背面でウィンドウ宛てキー入力を受け付けないゲームには対応していません。未知ゲームでの長時間運転や有用な自己改造の成功は未検証です。Authenticode署名と署名付き本体自動更新は未設定です。
