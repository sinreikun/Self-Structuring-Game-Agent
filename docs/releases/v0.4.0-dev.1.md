個体管理とLLM管理を追加し、個体・設定・共有モデルを一貫して管理できるようにしました。

- 個体一覧・詳細・容量、ロード、名前変更、完全／設定のみ複製、NEWBORN、比較、完全エクスポート、削除に対応。旧個体をロード可能な資産として保持し、不要な個体だけ明示的に削除できます。
- 個体をロードすると保存設定をGUIへ反映し、指定した保存済みLLMのRuntimeとモデルを自動準備します。共通設定・モデル本体は個体間で共有します。
- ESCなどのキー末尾追加で経験・研究・Checkpoint・Revisionを引き継げます。入力番号を変える並べ替え・削除と別ゲームへの変更は理由を表示します。
- LLM管理でモデル検索・条件フィルタ・保存済み一覧・詳細・導入・スタンバイ・使用・停止・削除をまとめました。モデルと参照個体の関係を表示します。
- スタンバイは実際にRuntimeへロード済みの状態です。同時ロードを1モデルに制限し、使用中／スタンバイ中の削除を防止します。指定モデルがない場合は勝手に置き換えません。
- Context・CPUスレッド数・Runtime設定を個体へ保存し、起動引数に反映します。個体ごとにログを分離し、診断ZIPへ選択個体のプロフィール・設定・ログを追加します。

旧版が保存していなかった非アクティブ個体の設定は自動復元できません。個体管理の「設定を補完」で当時のゲーム・キー順序・モード・LLMを確認してからロードしてください。既存のDB・画像・Checkpointを移行時に削除しません。詳しくはdocs/individual-management.mdをご覧ください。
