# 過去個体の未参照画像の整理案（承認待ち・未実装）

公開済みv0.2.0-dev.1のGCは現在の個体が対象です。過去個体の自動整理は行いません。以下の追加変更は、自動承認レビューが「過去個体の削除範囲の明示承認がない」として拒否したため適用していません。

## 追加する場合の範囲

対象は設定された作業フォルダの `experiments/<過去個体ID>/evidence/*.png` だけです。現在の個体を扱うGCに加え、容量不足時に過去個体を順に確認し、原画像の保持対象から外れた経験を統計へ集約した後、どの保持対象からも参照されなくなった画像だけを削除します。1回最大512経験・128画像に制限します。

以下は削除しません。

- Knowledge・仮説・支持・反証から参照される根拠
- 採用・重要な棄却・比較失敗の評価根拠
- 異常・復旧の前後、再現用、代表例として保護された根拠
- 未完了研究の根拠、入力処理の途中の根拠
- 直近128件、代表例、予測逸脱例等の保持枠に含まれる画像
- DB・Knowledge・Reports・設定・チェックポイント・Agent世代・Agent作業ファイル・モデル・アプリ本体

未完了研究の保護範囲が特定できない個体や、リンク先など範囲が不明な保存先は整理しません。削除済み画像を元に完全な原画像Replayを行えるとは扱いません。画像参照の解除をDBへコミットしてからファイルを削除します。

## Newbornとの境界

Hostの保持管理だけが過去DBの根拠IDを照合します。過去の文章・画像・仮説・学習状態を現在のAgentやScientistへ渡しません。現在の個体の経験数やKnowledgeは増やしません。

## 確認項目

旧個体の重要根拠が残ること、未参照画像だけが整理されること、未完了研究を保護すること、整理後もNewbornの経験・Knowledgeが空のままであることを検証します。固定Launcherを取り直さず、本体だけ更新する方式を維持します。
