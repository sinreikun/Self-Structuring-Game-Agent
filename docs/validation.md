## 未検証・配布上の条件

| 条件 | 現在の状態 |
| --- | --- |
| Windowsの画面取得・入力・入力解放・再起動 | Windows CIのテスト用ウィンドウで確認。各利用者の実ゲーム・描画環境での確認は別途必要 |
| Windows単体EXEの生成と起動 | Windows CIで生成・梱包後自己診断を確認 |
| 署名済み本体更新の取得・置換・失敗時復旧 | 実装あり。公開鍵・実配布元が未設定のため実配布では未検証 |
| 未知ゲームでの長時間無人稼働 | 未検証 |
| 複数ゲームの概念・技能形成と転移 | 未検証。現在の評価は主に画面変化の予測であり、ゲーム進行の成功指標ではない |
| ゲームを別プロセスへ渡すランチャー | 非対応。直接起動したPIDのウィンドウだけを対象とする |
| 背面での入力・取得 | ウィンドウ宛て入力と隔離WorkerによるPrintWindow取得へ変更。最小化は対象外。Raw Input専用などのゲームは非対応 |
| あらゆる描画方式・非表示ウィンドウ | 保証しない。デスクトップ画素や全体キーボード入力への代替は行わない |
| 外部ネイティブDLLの自動採用 | Agentへ直接ロードする経路は提供していない |

自動テストの成功だけで完成版や長期安定性を宣言しません。Windows用の配布物、署名付き更新元、実機I/Oと長時間運転の結果がそろうまでは開発版として扱います。
